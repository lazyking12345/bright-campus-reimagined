# Gaudium Elevated

Act as an elite UI/UX designer and full-stack developer specializing in modern, accessible educational websites.

I want you to completely redesign and rebuild the website for [the-gaudium].

Base the content structure, navigation, and core pages on their current website: [https://www.thegaudium.com]. However, DO NOT clone their old design. Instead, build a beautiful, high-converting, modern web application using the following guidelines:

Visual Identity & Aesthetic:

Clean, modern layout with plenty of whitespace, bold typography, and rounded bento-grid style cards.

Use a professional, sophisticated color palette inspired by the school's official colors (primary, secondary, and accent).

Include high-quality hero sections with placeholders for vibrant campus imagery and video backgrounds.

Navigation & User Personas:

Create an intuitive, mega-menu navigation bar optimized for three distinct user groups: Prospective Families, Current Students/Parents, and Staff.

Key pages to include/simulate: Home, About Us, Academics, Admissions, Athletics, and a Contact/Location portal.

Key Modern Features to Build:

Hero Section: An impactful tagline, quick-action buttons (e.g., "Tour Campus", "Apply Now"), and an interactive statistics counter (e.g., "98% Graduation Rate", "15:1 Student-Teacher Ratio").

Dynamic Notice Board/News Feed: A clean, filterable section for recent school announcements and upcoming events.

Quick Links Grid: A beautiful grid for high-traffic pages (Parent Portal, Lunch Menus, Calendar).

Testimonials Slider: A section showcasing glowing quotes from parents and students.

Technical Standards:

100% mobile-responsive design.

Strictly follow WCAG AA accessibility standards (high contrast, readable fonts, clear button states).

Use smooth micro-interactions, hover effects, and fade-in animations to make the site feel premium and expensive.
